Privacy Policy

Last Updated: September 10, 2026

This Privacy Policy explains what data Minecraft Monitor ("the Bot") collects, how it is used, how it is stored, and your rights regarding your data.

1. Data We Collect

To function properly, the Bot collects and stores minimal data required to track Minecraft server statuses and manage your Discord server preferences:

  • Discord Guild (Server) IDs: Stored to maintain server-specific configurations and monitoring settings.
  • Discord Channel IDs: Stored to manage voice channels and text messages designated for status displays.
  • Discord User IDs: Processed to verify command permissions, process bug reports, and enforce rate limits.
  • Minecraft Server Addresses & Ports: IP addresses, domain names, and port numbers configured for status checks.
  • Custom Server Settings: Custom nicknames, indicators, or preference flags set for monitored servers.

Note: The Bot does not read or store standard text chat in your Discord channels, nor does it collect private personal conversations.

2. How We Use Collected Data

The data collected is strictly used to:

  • Periodically query specified Minecraft servers and automatically update status channels and messages.
  • Preserve guild preferences (such as custom online/offline indicators or default server settings).
  • Maintain system security, prevent API abuse, enforce rate limits, and resolve technical bugs.

3. Data Storage and Security

All persistent data (such as server settings, IP addresses, and channel IDs) is stored in private, self-hosted databases. We implement reasonable technical security measures to protect stored data.

4. Data Sharing and Disclosure

We do not sell, trade, rent, or share your data with third parties. Data is only processed to provide the Bot's core services or if required by law.

5. Data Retention & Deletion

  • Removal of the Bot: Unmonitoring a server or kicking/banning the Bot from a Discord server halts all status requests.
  • Data Removal Requests: Server owners can request the manual deletion of all stored guild settings, server IPs, and associated IDs by contacting us directly.

6. Children’s Privacy

The Bot is not intended for children under the age of 13 (or 16 depending on local jurisdiction). We do not knowingly collect personal information from children in violation of applicable laws.
